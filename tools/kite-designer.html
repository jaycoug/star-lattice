Kite Designer

Draw a pattern for each category's kite. The grid is the halves pattern: 3 vertical, 3 horizontal and 3 + 3 border-parallel lines, plus the wide and long inner kites (64 regions). Designs are saved in this browser; Export writes them to a file, which PLAY's Design… can import. The same editor is on PLAY (a kite's card › Design…), where designs belong to the content set.
